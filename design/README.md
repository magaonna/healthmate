# 짐짝 GYMJJAK

우리 동네에서 같이 운동할 헬스메이트를 찾는 모바일 웹 서비스의 디자인 시스템입니다. 크림(KREAM)과 마켓컬리처럼 흑백 위주로 차분하고 정돈된 화면을 만듭니다. 색은 검정 한 가지로 강조하고, 나머지는 회색 단계와 여백, 글자 굵기 차이로 정리합니다.

- 방향: A안 블랙 모노톤 (2026-10-28 대표 확정)
- 작성: 윤하린(디자인) · 2026-10-28
- 상태: **대표 승인 대기**. 승인되면 강민재가 `public/style.css`를 이 토큰으로 바꾸고 전 화면에 적용합니다.
- 기준 화면: 모바일 375px 폭

## 1. 원칙 다섯 가지

1. **강조는 검정 하나.** 주 버튼, 선택된 탭, 핵심 숫자만 `ink-900`. 초록·노랑·파랑·연두는 모두 없앱니다. 빨강(`danger`)은 오류와 안 읽음 뱃지에만 씁니다.
2. **이모지 금지.** 서비스 화면, 알림 문구, 기본 프로필 사진, 지도 마커 어디에도 쓰지 않습니다. 필요한 곳은 Lucide 선형 아이콘 한 세트로 바꿉니다.
3. **카드 대신 구분선.** 회색 바탕 위 흰 카드와 그림자를 쓰지 않습니다. 흰 바탕 위에 `gray-200` 1px 선으로 행을 나눕니다.
4. **정보는 한 행에 하나의 주인공.** 목록 한 행에서 크게 보이는 것은 닉네임과 3대 합계 하나뿐입니다. 나머지는 `gray-600` 작은 글자 한 줄로 이어 씁니다. 색 태그 5~6개를 쌓지 않습니다.
5. **넉넉한 여백.** 화면 좌우 20px(`space-5`) 고정, 모든 간격은 4의 배수입니다.

## 2. 색

| 토큰 | 값 | 어디에 |
|---|---|---|
| `ink-900` | #111111 | 주색. 제목·본문 글자, 주 버튼, 선택 상태, 지도 마커 |
| `ink-700` | #3D3D3D | 주 버튼 누름 상태 |
| `gray-600` | #5E5E5E | 보조 글자 (거리, 지역, 소개) |
| `gray-500` | #767676 | 3순위 글자 (시간, 캡션). 흰 바탕에서만 |
| `gray-400` | #8F8F8F | 입력칸·보조 버튼 테두리. 글자에 쓰지 않음 |
| `gray-200` | #EBEBEB | 구분선 |
| `gray-100` | #F4F4F4 | 옅은 채움 (꺼진 칩, 기본 프로필 원, 검색칸) |
| `white` | #FFFFFF | 바탕 |
| `danger` | #D92D20 | 오류, 되돌릴 수 없는 버튼 글자, 안 읽음 뱃지 |

글자 대비는 모두 4.5:1 이상입니다. `gray-500`은 `gray-100` 위에서 4.1:1이라 기준에 못 미치므로, 옅은 채움 위 글자는 `gray-600`을 씁니다.

## 3. 글꼴

**Pretendard** 한 가지만 씁니다 (OFL 라이선스, 상업 사용 가능). 지금 화면은 글꼴 목록에만 적혀 있고 실제로는 불러오지 않습니다. 앞으로는 웹폰트 파일(`fonts/PretendardVariable.woff2`)을 직접 불러옵니다.

| 스타일 | 크기/줄높이 | 굵기 | 어디에 |
|---|---|---|---|
| `display` | 28/36 | 700 | 로그인 큰 제목, 프로필의 3대 합계 |
| `title` | 22/30 | 700 | 화면 제목 (화면당 하나) |
| `heading` | 18/26 | 600 | 구역 제목, 모달 제목 |
| `body` | 16/24 | 400 | 본문, 입력칸. 버튼 글자는 600 |
| `body-sm` | 14/20 | 400 | 목록 보조 정보. 칩 글자는 500 |
| `caption` | 12/16 | 500 | 시간, 탭바 글자, 법적 안내 |

- 굵기는 400·500·600·700 네 가지만 씁니다. 지금 남용 중인 800은 없앱니다.
- 크기는 위 6단계만 씁니다. 지금은 10가지가 넘습니다.
- 숫자(3대 기록, 거리)에는 `font-variant-numeric: tabular-nums`를 넣어 자릿수를 맞춥니다.

## 4. 간격·모서리·크기

- 간격: 4 · 8 · 12 · 16 · 20 · 24 · 32 · 48 (`space-1`~`space-12`)
- 모서리: 칩 4px, 버튼·입력칸·사진 8px, 프로필 원·마커·뱃지는 완전한 원
- 버튼·입력칸 높이 52px, 작은 버튼과 칩 36px, 상단 바 52px, 탭바 56px
- 누를 수 있는 영역은 최소 44×44px

## 5. 아이콘

**Lucide** 선형 아이콘 한 세트 (ISC 라이선스, 무료). 선 두께 1.75, 끝은 둥글게.

- 크기: 탭·상단 바 24px, 버튼·목록 안 20px, 글자 옆 16px
- 색은 글자와 같게 둡니다 (`ink-900`, 꺼진 상태 `gray-400`). 아이콘에만 색을 넣지 않습니다.
- 아이콘만 있는 버튼에는 화면 낭독기용 이름(`aria-label`)을 붙입니다.

## 6. 구성 요소 규칙

**버튼**
- 주 버튼: `ink-900` 채움, 흰 글자 16/600, 높이 52, 모서리 8. 한 화면에 하나.
- 보조 버튼: 흰 바탕, `gray-400` 1px 테두리, `ink-900` 글자.
- 글자 버튼: 배경 없이 `ink-900` 글자에 밑줄. "회원가입", "다시 보내기" 등.
- 위험 버튼: 보조 버튼 모양에 `danger` 글자. 신고, 차단, 탈퇴.
- 꺼짐: `gray-100` 채움, `gray-500` 글자.

**입력칸**
- 높이 52, 흰 바탕, `gray-400` 1px 테두리, 모서리 8, 안쪽 좌우 16.
- 라벨은 칸 위에 14/500 `ink-900`. 입력 중 테두리 `ink-900` 2px.
- 오류: 테두리와 아래 안내문 모두 `danger`, 안내문은 무엇을 고치면 되는지 씁니다.

**목록 행 (메이트·쪽지·채팅)**
- 왼쪽 48px 프로필 원, 오른쪽 내용, 위아래 16 여백, 아래 `gray-200` 1px 선.
- 첫 줄: 닉네임 16/600 + 오른쪽 끝에 거리나 시간 (12/500 `gray-500`).
- 둘째 줄: "3대 420kg" 14/600 `ink-900` + 성별·나이·구력 14/400 `gray-600`.
- 셋째 줄(있으면): 운동 요일·시간·헬스장을 " · "로 이어 14/400 `gray-600`, 한 줄 넘치면 말줄임.

**칩 (필터)**
- 높이 36, 모서리 4, 글자 14/500.
- 꺼짐: `gray-100` 채움, `ink-900` 글자. 켜짐: `ink-900` 채움, 흰 글자.

**하단 탭바**
- 흰 바탕, 위에 `gray-200` 선, 높이 56. 아이콘 24 + 글자 12/500.
- 선택: `ink-900`. 나머지: `gray-500`. 안 읽음 수는 `danger` 원형 뱃지.

**지도**
- 모서리 8, 지도 위 내 위치는 `ink-900` 점과 흰 테두리, 반경 원은 `ink-900` 8% 채움.
- 메이트 마커: 32px `ink-900` 원 + 흰 글자 닉네임 첫 글자.
- 지도를 못 불러오면 `gray-100` 상자에 "지도를 불러오지 못했어요" 한 줄.

## 7. 문구

- 해요체로 짧고 정중하게. 한 문장에 한 가지만.
- 느낌표와 감탄사를 쓰지 않습니다. "필터를 줄이거나 반경을 넓혀 보세요!" → "필터를 줄이거나 반경을 넓혀 보세요."
- 오류 문구는 탓하지 않고 다음 행동을 알려 줍니다. "잘못 입력했어요" → "비밀번호는 8자 이상 입력해 주세요."
- 개발자용 말(Supabase, config.js, SQL)은 사용자 화면에 쓰지 않습니다.
- 숫자와 단위는 붙여 씁니다: 420kg, 0.8km, 3분 전.
