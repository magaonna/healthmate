헬스 메이트 v2

v1은 찾기·프로필·글쓰기·채팅·인증·1RM 영상 인증까지 핵심 화면이 잘 잡혀 있었습니다. 다만 화면과 화면 사이가 비어 있어서, 요청을 보낸 뒤와 약속을 잡은 뒤에 무슨 일이 일어나는지가 없었습니다. v2는 그 연결 고리를 채우고, 오른쪽 폰에서 모든 버튼이 실제로 동작하게 만들었습니다.

v1에서 그대로 살린 것

  • 3대 1RM을 신뢰 지표로영상 인증과 자기 신고를 구분해 보여주는 방식
  • 인증 코드 방식의 영상 인증4자리 코드를 영상에 보이게 해서 재활용 영상을 막음
  • 첫 만남은 헬스장 안에서안전 원칙을 프로필·채팅에 고정 노출
  • 메이트와 주간 목표매칭 이후에도 앱을 다시 열 이유

비어 있던 곳과 v2에서 채운 것

  • 필터 칩이 "벤치 80kg+" 같은 고정값내 1RM으로 조건 충족 여부를 카드마다 자동 판정하고, 종목·오늘·시간대·조건 충족·인증·동성 필터와 반경, 정렬이 실제로 동작
  • 구인 글에 모집 상태가 없음모집중·마감·내 글·요청 보냄 상태와 신청자 수 표시. 번개 글은 한 명 수락하면 자동 마감
  • "메이트 요청하기" 다음 화면이 없음요청 시트에서 어느 글에 요청하는지 고르고, 조건 미달이면 이유와 해결 방법(영상 인증)을 바로 안내
  • 받은 요청을 처리할 곳이 없음받은 요청 수락·거절. 거절은 상대에게 "다른 메이트와 매칭됐어요"로 부드럽게 안내
  • 약속 카드가 "확정 대기"에서 끝남확정 → 헬스장 도착 체크인 → 운동 완료 → 후기·노쇼 신고. 프로필의 "노쇼 0회"가 여기서 쌓임
  • 신고는 "오른쪽 위 메뉴" 안내만 있음신고·차단 시트 구현. 채팅에 전화번호·카톡 아이디가 오가면 주의 안내를 띄움
  • 자기 신고 1RM도 조건 통과글쓰기에 "영상 인증된 1RM만 받기" 옵션, 스팟 조건 권장값(작업 중량의 80%) 안내, 입력 검증과 미리보기
  • 인증 탭 기록이 숫자 나열사진 인증 시 최고 세트로 추정 1RM(Epley)을 계산. 내 1RM보다 높으면 영상 인증으로 갱신하도록 유도
  • 영상 인증 신청 후 상태 변화가 없음코드 24시간 카운트다운, 코드 재발급, 검토 중·통과·반려 흐름과 반려 사유, 종목별 판정 기준 시트
  • "내 정보" 탭이 비어 있음내 1RM, 신뢰 지표(함께한 운동·노쇼·늦은 취소), 내 글 관리, 안전 설정(동성에게만 받기, 위치 공개 범위, 차단 목록)
  • 알림이 없음알림 센터. 요청 수락, 새 요청, 인증 결과를 누르면 해당 화면으로 이동

동업자와 같이 눌러볼 순서

  1. 요청 보내기

    홈에서 메이트C 글을 열고 요청을 보내면 몇 초 뒤 수락 알림이 오고 채팅이 열립니다.

  2. 약속부터 후기까지

    메이트A 채팅에서 약속 확정 → 체크인 → 운동 끝 → 후기를 남겨 보세요. 프로필 숫자가 바뀝니다.

  3. 받은 요청 처리

    채팅 탭 위쪽의 받은 요청을 수락하거나 거절해 보세요.

  4. 글 올리기

    글을 올리면 잠시 뒤 새 요청이 들어옵니다.

  5. 오늘 인증과 1RM 갱신

    예시 사진으로 인증하고, 추정 1RM 배너에서 영상 인증으로 넘어가 보세요.

개발 전에 정해야 할 것

  • 노쇼 페널티몇 번부터 요청 제한을 걸지, 늦은 취소(2시간 이내)를 노쇼와 같게 볼지
  • 영상 검토 주체운영자가 직접 볼지, 인증된 상위 회원이 교차 검토할지. 초기엔 운영자 검토 + 24시간 SLA 권장
  • 체크인 위치 확인헬스장 반경 100m GPS로 충분한지, 헬스장 QR을 붙일지
  • 헬스장 인증"같은 헬스장" 표시를 회원권 사진으로 확인할지, 자기 선택으로 둘지
  • 고정 메이트 이후고정 매칭이 성사되면 글을 자동 마감할지, 인원 제한(예: 2명)을 둘지
